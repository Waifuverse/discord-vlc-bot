# GroupVid — Discord VLC Remote

Let friends control the VLC player you screen-share in Discord. Run this bot on the Windows PC playing the video; everyone in your chosen channel can play, pause, skip backward or forward, browse shows and build a shared playlist.

Discord screen sharing carries the video and audio. This is a self-hosted remote for one VLC instance, server and channel. It does not broadcast video as a bot or require a Discord Activity, public web server or paid API.

## Quick start

Install **Windows 10/11**, **Python 3.11+** (available as `python` in PowerShell), **VLC 3.x** and Git. Use a standard VLC installation, or add your VLC executable's folder to `PATH`.

```powershell
git clone https://github.com/Waifuverse/discord-vlc-bot.git
cd discord-vlc-bot
powershell -ExecutionPolicy Bypass -File .\setup.ps1
notepad .env
```

You can also download and extract the repository ZIP, then open PowerShell in that folder and run `setup.ps1`.

Setup installs dependencies in `.venv` and creates your actual **`.env`**, ready to fill in, with a unique VLC password. Existing `.env` files are preserved. The public [config.env.template](config.env.template) contains blank credential fields; edit the generated `.env`, not the template. For guided setup with hidden token entry, use `setup.ps1 -Interactive`.

## Create and invite your Discord bot

1. Create a **dedicated application** in the [Discord Developer Portal](https://discord.com/developers/applications). Choose any bot name you like.
2. On **Bot**, generate/reset the bot token and enter it as `DISCORD_TOKEN` in your private `.env`. Use the token without a `Bot ` prefix. No client secret or public key is needed.
3. On **Installation**, enable **Guild Install**. Set scopes to **bot** and **applications.commands**. Grant **View Channels**, **Send Messages**, **Embed Links** and **Read Message History**.
4. Open that application's installation link and add it to your server using an account allowed to manage the server. Privileged Gateway intents are unnecessary. Leave **Interactions Endpoint URL** empty; this bot uses an outbound Gateway connection.
5. In Discord, enable **User Settings → Advanced → Developer Mode**. Right-click your server and control channel to copy their IDs. You can also copy your user ID and an optional controller role ID.

Use your own dedicated bot application. Startup synchronizes its commands in the configured server; sharing an application with unrelated bot code could replace those commands. Each installation uses its own invite link from the Developer Portal.

## Fill in `.env`

| Setting | What to enter |
| --- | --- |
| `DISCORD_TOKEN` | Required: your application's bot token. |
| `DISCORD_GUILD_ID` | Required: the server ID. |
| `DISCORD_CHANNEL_ID` | Required: the text channel or voice channel's text chat for the remote. |
| `HOST_USER_ID` | Optional: the host's user ID. Members with **Manage Server** are also hosts. |
| `CONTROL_ROLE_ID` | Optional: restrict control to a role. Leave blank to let everyone in the control channel participate. Hosts bypass this role restriction. |
| `MEDIA_ROOT` | Folder containing your videos. Defaults to this project's `media` folder. Relative paths are resolved from the project folder; an absolute path such as `C:/Videos/Shows` also works. |
| `VLC_URL` | Keep `http://127.0.0.1:8080` unless you need another local port. Only loopback addresses are accepted. |
| `VLC_PASSWORD` | Keep the password generated by setup. The launcher and bot use it together. |

Save `.env`. The bot reads this installation's file regardless of your current working directory. Restart the bot after editing configuration. Never commit, force-add, screenshot or share a filled-in `.env`; it is ignored by Git along with runtime state and media. The blank template is the file distributed publicly.

## Start a watch session

Double-click **Start VLC Remote.cmd**, or run:

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

The launcher validates configuration, opens the controlled VLC window if needed, waits for its local interface and starts the bot. Keep the console open and the PC awake.

1. Screen-share the **controlled VLC window** in Discord with sound enabled.
2. As the host, run `/vlc panel` in your configured channel to post the shared remote.
3. Open a video in that VLC window, or use **Shows** to select one from your library.
4. Have friends use the buttons or slash commands. `/help`, `/vlc help` and the **Help** button explain the controls.

`Ctrl+C` stops the bot and leaves VLC running. The panel, host lock and saved playlist survive restarts. Only the main remote panel has persistent buttons; reopen temporary show/playlist views after a restart or timeout.

For separate startup and connection checks:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-vlc.ps1
powershell -ExecutionPolicy Bypass -File .\check-vlc.ps1
powershell -ExecutionPolicy Bypass -File .\start-bot.ps1
```

The launcher starts a separate VLC instance bound to loopback. Open files inside that controlled window. No router port forwarding is needed.

## Commands and shared access

| Command | Action |
| --- | --- |
| `/help` or `/vlc help` | Show the public guide, even if VLC is offline or the remote is locked. |
| `/vlc panel` | Host: create the persistent remote, or return its existing link. |
| `/vlc play` | Resume playback. |
| `/vlc pause` | Pause; repeated calls remain paused. |
| `/vlc rewind seconds:15` | Go back 15 seconds; accepts 1–3600 seconds. |
| `/vlc forward seconds:15` | Go forward 15 seconds; accepts 1–3600 seconds. |
| `/vlc status` | Show the current item, playback position and lock status. |
| `/vlc shows` | Browse available shows, versions and episodes. |
| `/vlc playlist` | View, edit, reorder and start the saved playlist. |
| `/vlc next` | Go to the next item in VLC's active queue. |
| `/vlc previous` | Go to the previous item in VLC's active queue. |
| `/vlc lock` | Host: restrict playback and playlist changes to hosts. |
| `/vlc unlock` | Host: restore normal shared control. |

The panel also has **Back 10s**, **Back 30s**, forward equivalents and **Custom skip** for signed seconds such as `-15` or `+90`. Controls run sequentially, have a per-person cooldown and clamp seeks to media boundaries.

Help, playback confirmations and show/playlist views are public. Authorized members can use the same shared editor. Access denials are private. By default, everyone who can use the configured channel can control playback; voice-call membership is not required. Use a private channel, `CONTROL_ROLE_ID`, or the host lock to limit access.

To make commands available to everyone, allow **View Channel** and **Use Application Commands** for the intended members, and check **Server Settings → Integrations → your app** for command restrictions. The bot needs its four channel permissions listed above. Help can be opened in other channels of the configured server to find the control channel.

## Organize shows and build a playlist

The first folder below `MEDIA_ROOT` becomes the show name. Episode filenames containing `Subbed` or `Dubbed` form separate versions; others are marked **Unlabelled**. Episodes are sorted naturally, so episode 2 comes before episode 10. For example:

```text
media/
  Example Show/
    Episode_01_Subbed.mp4
    Episode_02_Subbed.mp4
    Episode_01_Dubbed.mp4
  Another Show/
    Episode_01.mkv
```

See [media/README.md](media/README.md) for supported formats and layout details. Media files are not included in this repository.

1. Open **Shows** and select a show/version, then an episode. Use **Play episode now** for immediate playback, **Add episode**, or **Add this version in order**.
2. Open **Playlist**. Select an entry and choose **Move up**, **Move down**, **Move to position** or **Remove episode**. You can combine shows/versions and intentionally add duplicate episodes, up to 100 entries.
3. **Clear saved playlist** requires a second click and removes entries only; it does not delete videos.
4. When ready, click **Start playlist from beginning**. This replaces VLC's active queue and starts the first entry in your saved order. Shuffle/repeat are disabled when applying it.

Edits save immediately to local runtime state and leave current playback alone. Apply the new order by starting the playlist again. **Play episode now** replaces VLC's queue with one episode while retaining the saved draft. **Next/Previous** follow VLC's active queue. An outdated editor must refresh before overwriting someone else's changes.

Reopen **Shows** to rescan after adding videos. Keep files inside `MEDIA_ROOT`; the bot rejects paths outside it and does not accept arbitrary URLs or filesystem paths from Discord users.

## Troubleshooting

- **Missing commands:** start the bot and check its console; confirm the configured server ID, Guild Install and `applications.commands` scope. Check channel permissions and app command restrictions. Commands are server-only, not available in DMs.
- **Cannot reach VLC:** run `check-vlc.ps1`. Use the controlled VLC window. If port 8080 is occupied, choose another loopback port in `.env`, then restart the controlled VLC and bot.
- **Wrong VLC password:** close the controlled VLC window and relaunch it. Editing `.env` does not update an already running VLC interface.
- **No permission to create the panel:** set `HOST_USER_ID` or use a member with **Manage Server**. Check the bot's channel overrides as well.
- **Remote or editor stops responding:** keep the bot running and PC awake. Reopen temporary editors. Restarting the bot restores the main panel; a deleted panel can be recreated with `/vlc panel`.
- **Empty Shows list:** check `MEDIA_ROOT` and supported extensions. Restart after changing `.env`, then reopen Shows.
- **A skip times out:** read Status before retrying; VLC may have received a request even if its response was lost. Live sources may not support seeking.
- **Already running:** close the existing bot console. `stop-bot.ps1` can stop a background instance recorded in `.state/bot.pid`; it does not close VLC.
- **No stream audio:** enable sound in Discord's screen-share UI. This bot controls playback and does not join voice or carry audio.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v

```

Tests use local fixtures and do not need a Discord token or installed VLC. GitHub Actions runs them on Windows with Python 3.11, 3.12 and 3.13, and checks tracked files for private configuration.
